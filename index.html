LinkedList Class

A custom Python implementation of a singly linked list with extended functionality including insertion, deletion, traversal, filtering, mapping, and more.

Methods and Examples

append(data)

Adds a new node with the given data to the end of the list.

ll.append(10)

push(data, index=None)

Inserts a new node. If index is provided, inserts at that position; otherwise, appends to the end.

ll.push(5, 0)

pop(index=None)

Removes and returns the last node or the node at a specific index.

ll.pop()

insertBefore(target, data)

Inserts a new node with the given data before the first occurrence of target.

ll.insertBefore(10, 5)

insertAfter(target, data)

Inserts a new node after the first occurrence of target.

ll.insertAfter(10, 15)

removeByValue(value)

Removes the first node that contains the specified value.

ll.removeByValue(10)

clone()

Creates and returns a deep copy of the list.

new_ll = ll.clone()

reverse()

Reverses the linked list in place.

ll.reverse()

findIndexOf(data)

Returns the index of the first node containing the specified data.

ll.findIndexOf(10)

indexOfAll(data)

Returns a list of all indices where the specified data is found.

ll.indexOfAll(10)

contains(data)

Checks if the list contains the specified data.

ll.contains(10)

isEmpty()

Checks if the list is empty.

ll.isEmpty()

toList()

Returns a Python list containing all data from the linked list.

ll.toList()

fromList(arr)

Populates the linked list using elements from a Python list.

ll.fromList([1, 2, 3])

merge(otherList)

Appends all elements from another LinkedList to the current list.

ll.merge(another_ll)

removeDuplicates()

Removes duplicate values from the list.

ll.removeDuplicates()

detail()

Returns a detailed view of each node, including data and memory address.

ll.detail()

sliceLinkedList(start, end)

Returns a sublist from index start to end (exclusive).

ll.sliceLinkedList(0, 3)

replace(old, new)

Replaces all occurrences of old with new.

ll.replace(10, 20)

map(function)

Applies a function to each element in the list.

ll.map(lambda x: x * 2)

filteredList(function)

Returns a new LinkedList with elements that satisfy the function condition.

ll.filteredList(lambda x: x % 2 == 0)

reduceList(function, initializer=None)

Reduces the list to a single value using the function.

ll.reduceList(lambda acc, x: acc + x, 0)

min()

Returns the minimum value in the list.

ll.min()

max()

Returns the maximum value in the list.

ll.max()

sortedList(mode)

Returns a sorted copy of the list. Modes: "asc", "desc", "reverse", "random".

ll.sortedList("asc")

clear()

Clears the entire linked list.

ll.clear()

docs()

Prints a placeholder message linking to the documentation.

ll.docs()

__len__()

Returns the number of nodes in the list.

len(ll)

__str__()

Returns a string representation of the linked list.

print(ll)

__iter__()

Enables iteration over the list using a loop.

for value in ll:
    print(value)

__getitem__(index)

Accesses the element at a given index.

ll[0]

__setitem__(index, value)

Sets the element at the given index to a new value.

ll[0] = 99

Basic Usage

ll = LinkedList()
ll.append(1)
ll.push(0)
ll.insertAfter(1, 2)
print(ll)  # Output: [0]->[1]->[2]-> None

Example Operations

# Double all values
ll.map(lambda x: x * 2)

# Filter even numbers
new_list = ll.filteredList(lambda x: x % 2 == 0)
